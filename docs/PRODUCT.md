# 产品方案：Mac 录屏工具（暂定名 **Takes**）

> 一句话定位：像 Screen Studio 一样录出来就好看，但**录得更从容**（随时暂停、分段重录）、**讲得更清楚**（点一下就框住重点、实时标注）、**发得更放心**（自动打码），而且**录过的东西都找得回来**（可搜索的录制历史）。

---

## 1. Screen Studio 拆解

### 1.1 它为什么好用（核心设计思想）

Screen Studio 最关键的设计是**"录制与渲染分离"**：

- 录屏时**不把鼠标烧进画面**，而是单独记录鼠标坐标、点击、键盘事件。
- 编辑/导出时再把鼠标"重新画"上去，所以可以做平滑轨迹、放大光标、静止时隐藏光标。
- 因为知道每次点击的位置和时间，所以能**自动生成镜头推拉（auto zoom）**，画面跟着操作走。

这套思想我们要完整继承，它是一切"自动化好看"的地基。

### 1.2 功能清单

| 类别 | 功能 |
|---|---|
| 录制 | 全屏 / 窗口 / 区域；麦克风 + 系统声音；摄像头画中画；iPhone 镜像录制 |
| 自动美化 | 点击自动缩放、镜头平滑跟随、动态模糊 |
| 光标 | 轨迹平滑、光标放大、静止隐藏、点击动效 |
| 画面包装 | 背景（渐变/壁纸）、内边距、圆角、阴影、比例裁切（16:9 / 9:16 / 1:1） |
| 编辑 | 剪切、变速、手动调整缩放区间、按键显示 |
| 导出 | MP4 / GIF、预设分辨率、分享链接 |

### 1.3 它的短板（我们的机会）

1. **录制过程"一口气"**：心理压力大，讲错一句只能后期剪；缺少"暂停 → 想一想 → 接着录"以及"这一段重录"的流程。
2. **没有"讲解"能力**：想强调某个按钮，只能靠缩放，不能画框、打箭头、编号步骤。
3. **隐私处理靠手工**：录到邮箱、手机号、API Key、微信弹窗，要在后期一帧帧处理。
4. **录完就散**：录过的东西是一堆文件，不能按内容找回。
5. **订阅价格偏高**，对国内用户也不太友好（没有中文字幕、本地化素材）。

## 2. 我们的差异化功能

### 2.1 ⏸ 随时暂停 + 分段录制（Takes）——核心卖点

- **全局快捷键暂停/继续**（如 `⌥⌘P`），菜单栏图标显示状态。
- 每次暂停自动切出一个**片段（Take）**，编辑器里片段像"章节"一样排列。
- **继续录制前**：显示上一帧的半透明叠影，帮你把窗口/鼠标对回原位，再 3-2-1 倒计时继续。
- **"重录上一段"**：讲砸了按一下，丢掉最后一段直接重来，不用停止整个录制。
- 片段之间可以选转场：直接拼接 / 淡入淡出 / 缩放过渡。
- 暂停期间可以切换录制区域（比如从窗口 A 换到窗口 B）。

### 2.2 🎯 点一下就框出重点（智能高亮）

这是你提的点子，我们把它做到"零手工"：

- 录制时**按住一个修饰键（如 `Fn`）+ 点击**，自动在被点的元素上画框。
- 框的大小**不是猜的**：通过 macOS 辅助功能 API（AXUIElement）拿到鼠标下按钮/输入框/菜单项的**真实边界**，框正好贴住控件。拿不到时退回图像边缘检测。
- 框的样式：矩形框 / 圆角框 / 聚光灯（周围压暗）/ 放大镜。
- **步骤编号**：连续点几个地方，自动标 ①②③，适合做教程。
- 所有标注都是**独立图层**，录完还能改样式、改时长、删掉。

### 2.3 ✏️ 实时标注（录制中的白板）

- 快捷键呼出标注工具条：画笔、箭头、矩形、文字、荧光笔。
- 画笔笔迹几秒后自动淡出（"激光笔"模式），不挡后续画面。
- 同样是独立图层，后期可编辑。

### 2.4 🔒 打码（手动 + 自动）

- **手动打码**：在编辑器框选区域 → 马赛克 / 高斯模糊 / 纯色块；区域可设置起止时间，支持**跟随移动**（目标跟踪）。
- **自动敏感信息检测**：用系统 Vision OCR 扫描画面，正则识别 邮箱、手机号、身份证、银行卡、API Key/Token、IP 地址，一键全部打码，可逐条确认。
- **防泄露录制**：录制时排除指定 App（微信、钉钉、密码管理器），它们的窗口直接不进画面；系统通知横幅自动屏蔽。

### 2.5 🗂 录制历史（可搜索的素材库）

- 首页就是**时间线式历史**：缩略图、时长、录制的 App、片段数。
- **按内容搜索**：录完后台对画面做 OCR，可以搜"上周录的那个有 'Deploy' 按钮的视频"。
- 标签、收藏、文件夹；按 App / 日期筛选。
- **崩溃恢复**：录制文件分片实时写盘，断电/崩溃后历史里仍能恢复。
- 存储管理：显示占用空间，一键清理原始素材只保留成片。

### 2.6 继承 Screen Studio 的基础能力

自动缩放、光标平滑/放大/隐藏、点击动效、背景/圆角/阴影、摄像头画中画、按键显示、多比例导出、MP4/GIF 导出、导出后自动复制到剪贴板。

## 3. 技术方案

### 3.1 技术选型

| 模块 | 方案 |
|---|---|
| 语言 / UI | Swift 6 + SwiftUI（部分 AppKit：菜单栏、悬浮窗、全屏标注层） |
| 屏幕捕获 | ScreenCaptureKit（`SCStream`，`showsCursor = false`，可排除指定 App） |
| 音频 | ScreenCaptureKit 系统音频 + AVCaptureSession 麦克风 |
| 摄像头 | AVCaptureSession |
| 写文件 | AVAssetWriter（HEVC/H.264，分片 MP4 便于崩溃恢复） |
| 输入事件 | `CGEventTap` 记录鼠标/键盘（需要辅助功能权限） |
| 控件边界 | Accessibility API：`AXUIElementCopyElementAtPosition` |
| 渲染 / 预览 | Metal + Core Image（缩放、光标、标注、模糊合成） |
| OCR / 跟踪 | Vision（`VNRecognizeTextRequest`、`VNTrackObjectRequest`） |
| 历史库 | 每个项目一个 `meta.json`，启动时扫描，内存检索（零依赖） |
| 最低系统 | macOS 15 Sequoia（用 ScreenCaptureKit 原生麦克风采集） |
| 分发 | 官网直接分发（App Store 沙盒会限制事件监听和辅助功能） |

### 3.2 架构

```
┌──────────────── 录制阶段 ────────────────┐
│ ScreenCaptureKit ─┐                      │
│ 麦克风 / 摄像头 ──┼─► Segment Writer ──► take-001.mp4, take-002.mp4 …
│ CGEventTap ───────┼─► events.jsonl  （鼠标、点击、按键，带时间戳）
│ 实时标注层 ───────┘─► annotations.json（含 AX 控件边界）
└──────────────────────────────────────────┘
                     │ 非破坏式
┌──────────────── 编辑 / 导出 ─────────────┐
│ 时间线模型（片段 + 缩放区间 + 标注 + 打码 + 字幕）│
│        └─► Metal 合成器 ─► 实时预览 / AVAssetWriter 导出
└──────────────────────────────────────────┘
```

**项目格式**：每次录制是一个 `.takes` 文件夹包：

```
2026-10-22 18-30 Xcode.takes/
├── meta.json          # 录制区域、分辨率、App、时长
├── segments/          # 每次暂停切一个文件
├── events.jsonl       # 输入事件轨
├── annotations.json   # 标注 / 打码图层
├── edit.json          # 编辑决策（剪切、缩放、样式）
└── thumbs/            # 历史缩略图
```

**暂停的实现**：暂停时结束当前片段文件，继续时开新文件，事件轨和时间线用"有效录制时间"对齐。这样"重录上一段"只是删一个文件，崩溃时最多丢一段。

### 3.3 权限

屏幕录制、辅助功能（事件监听 + 控件边界）、麦克风、摄像头。首次启动做一个引导页逐项授权。

## 4. 开发路线

| 阶段 | 目标 | 内容 |
|---|---|---|
| **P0 能录** | 1 周 | 菜单栏 App、权限引导、全屏/窗口/区域录制、麦克风+系统声音、**暂停/继续/重录上一段**、项目包落盘 |
| **P1 有历史** | 1 周 | 历史库首页、缩略图、播放、重命名/删除/标签、崩溃恢复 |
| **P2 好看** | 2 周 | 事件轨录制、光标重绘、自动缩放、背景/圆角/阴影、编辑器时间线、MP4/GIF 导出 |
| **P3 会讲** | 2 周 | **点击智能框选（AX 边界）**、步骤编号、实时标注工具条、标注后期编辑 |
| **P4 安全** | 1 周 | 手动打码 + 跟踪、OCR 敏感信息自动打码、排除 App、历史按画面文字搜索 |

---

## 5. 已确认

- 产品名 Takes，最低 macOS 15，官网直接分发。
- 不做「智能后期」（字幕、静音裁剪、图文教程）。
- 按 P0 → P4 顺序开发。
