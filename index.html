录完就好看，不用手动加特效

Takes 录制时不录光标，而是单独记下鼠标和点击，再把光标重新画出来。所以光标可以更大、更平滑，镜头也能自动放大到你点击的地方。

  • 按点击位置自动缩放，平滑跟随鼠标
  • 渐变背景、圆角、阴影，适配横屏、竖屏、方形
  • 按住 Fn 点按钮，自动画出贴合按钮的高亮框和步骤编号
  • 讲解声音自动调到合适的音量，并压低底噪

在片段或声音波形上拖动，选中想删的那几秒，按 ⌫，后面的内容自动接上。波形上能直接看到哪里在说话、哪里是停顿。

  • 鼠标悬停就能预览那一帧，不用拖动播放头
  • 选中后可以先播放这一段，确认了再删

四步装好

Takes 目前没有经过 Apple 公证，所以第一次打开需要多点一下确认。

  1. 下载点上面的下载按钮，得到 Takes.zip。
  2. 拖进「应用程序」双击解压，把 Takes 拖到「应用程序」文件夹。
  3. 第一次打开按住 Control 点 Takes，选「打开」，再点「打开」。如果仍被拦截，到「系统设置 → 隐私与安全性」点「仍要打开」。
  4. 授权按引导打开屏幕录制权限，然后重新打开 Takes。麦克风、摄像头按需开启。

常见问题

收费吗？

免费，源码公开在 GitHub。

怎么更新？

Takes 每天会自动检查一次 GitHub 上的新版本，有更新时弹窗提示，点「立即更新」会自动下载、安装并重启。也可以在菜单栏图标里点「检查更新…」。

录像存在哪里？

默认在「影片 / Takes」文件夹，每次录制一个文件夹，可以在设置里改位置。录像只保存在你的电脑上。

能录系统声音吗？

可以。系统声音、麦克风和摄像头可以同时录，摄像头画面会以画中画的方式显示。

录完还能改缩放和光标吗？

能。缩放、光标、标注、打码都是录完之后再加上去的，随时可以改，原始录像不会被改动。

为什么提示「无法验证开发者」？

因为 Takes 没有付费做 Apple 公证。按安装第 3 步操作一次即可，以后正常打开。
